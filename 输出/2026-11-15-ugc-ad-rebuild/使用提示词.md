## 本次排版与文字

本次使用程序排版，沿用已经提供给用户的预览。按原文顺序保留 7 步，最后一张卡合并生成验收与后期两步，编号 06–07。只使用流程和验收参数，省略案例价格、推广和第三方品牌资料

### 01 Read the Reference
- Watch the reference with sound · `VIDEO READ`
- Sample frames for the beats · `4 FPS`
- Sample around suspected cuts · `10 FPS`
- Use frames to verify shot count · `VISUAL QA`
- Take audio cues from the transcript · `TRANSCRIPT`

### 02 Write the Target
- Map the creator, product & room · `SWAPS`
- Map wardrobe, lighting & text · `DETAILS`
- Write one target sheet per clip · `TARGET`
- Make each visual check concrete · `PASS / FAIL`
- List reference details to exclude · `EXCLUSIONS`
- Verify the product can do it · `FEASIBILITY`

### 03 Plan the Clips
- Split at every hard cut · `SHOT MAP`
- Add trim room to each clip · `0.5–1 S`
- Plan how to lock key details · `CONSTRAINTS`
- Raise constraints one rung · `RETRY`
- Estimate the budget by clip · `BUDGET`
- Approve targets, cuts & budget · `GATE 1`

### 04 Build Start Frames
- Build one start frame per clip · `1 PER CLIP`
- Edit the reference for an exact pose · `EDIT`
- Generate new if the pose is flexible · `GENERATE`
- Lock wardrobe, room & framing · `CONTINUITY`
- Show the correct product state · `PRODUCT`
- Approve each frame vs. target · `GATE 2`

### 05 Build the Video Inputs
- Choose inputs for each clip · `BIND`
- Remove conflicting references · `NO CONFLICTS`
- Bind an input for each target row · `COVERAGE`
- Prompt for motion, camera & audio · `PROMPT`
- Get the quote after the input audit · `QUOTE`
- Approve the quote before each run · `GATE 3`

### 06–07 Generate, Check & Edit
- Pass clip 1 before the rest · `PILOT`
- Match frame 0 to the start frame · `MATCH`
- Reject leaks from the reference · `FAIL`
- Check all target rows in tiles · `4 FPS`
- Trim to match each reference cut · `~0.2 S`
- Add on-screen text in post · `OVERLAYS`
